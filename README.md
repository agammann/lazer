# Lazer

Lazer is a cyberpunk Bitcoin Testnet 4 trading platform being built for Alice and Bob, with Bitcoin Core integration and a simulated USD balance.

The product name is **Lazer**. The source repository is [agammann/lazer](https://github.com/agammann/lazer).

Development is in progress. A local trading terminal exists, but the complete funded account, deposit, trade, and withdrawal workflow has not yet been verified on Bitcoin Testnet 4. There is no published release or live hosted deployment yet.

Testnet bitcoin and simulated USD have no redeemable monetary value in this application. This project is not ready to accept mainnet bitcoin or real USD.

The engineering inspiration is Jane Street's [Building an Exchange](https://www.janestreet.com/tech-talks/building-an-exchange/).
